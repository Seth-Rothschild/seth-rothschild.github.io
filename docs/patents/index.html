As part of my regular work in the Office of the CTO, I created prototypes and submitted patent disclosures to Dell, a subset of which were filed with the US Patent Office. An up-to-date list of my granted and published patents is on Google Patents.

Some interesting inventions

  • Method and system for encrypting and decrypting secrets using escrow agents
    US11664988B2 · with Radia Perlman, Alex Robbins

    Suppose you have a very secret password that you can’t keep in a password manager, like the password to your password manager. While you could trust one “escrow provider” to encrypt and store this secret, it would be hard to prevent this provider from peeking. This patent is an invention of Radia Perlman’s that we prototyped, which describes a way to keep this secret in escrow so that a quorum of escrow providers need to grant access in order to reconstruct the secret.

  • System and method for encrypted storage of constructed data
    US12182285B2 · with Michael Thomas Kruzewski

    Plugging into existing access control systems, particularly at a large company, is hard. The main idea here is to make sharing of applications that use protected data easier, by gating app access behind a challenge that only someone with pre-existing access to the data could answer.

  • Secure password log in on insecure devices
    US11770412B2 · with Radia Perlman, Ben Santaus, Orlando Xavier Nieves

    Since passkeys are not widely adopted, we wondered if it would be possible to create a system that converts “what you have” into traditional username/password authentication. Our prototype did the login on a secure device and transferred the session cookie to the less secure device.

  • Continuous video generation from voice data
    US11553159B1 · with Alex Robbins

    We spend a lot of time on video calls, but not a lot of people like being on video. This invention provides an inexpensive way to be on video without being on video, by taking the audio input and manipulating the lips of an existing video of the user.

  • System and method to distribute access to shared accounts with a trusted intermediate service manager
    US12388824B2 · with Radia Perlman

    Teams often share one account on a third party service, and the usual way to do that is to pass the password around. The trick here is a deliberate man-in-the-middle: a trusted service inside the company holds the credentials, signs in on everyone’s behalf, and forwards only the parts of the third party UI it chooses to each user. Nobody else ever sees the password, and what each person can do is up to the company rather than the vendor.

  • Seamless multi-factor authentication code transfer
    US20250343790A1 · with Rana Amr Afifi Mohamed, Shary Beshara

    Until FIDO is widely adopted, which for many important services it still isn’t, logging in often means reading a code off your phone and typing it into your computer. This invention gives users a way to send that code from one device to the other without a human being reading or typing any numbers. It reduces friction without reducing security and without requiring external services to change their implementations.

  • Efficient method to find columns of a table which are unique
    US12026139B2 · with Brendan Burns Healy, Akshaya Khare, Kranti Uppala

    Sometimes you need to check many large columns quickly to find out whether a column is likely to be a primary key. The trick in this patent leans on the birthday problem: an extremely reasonable first filter is to check a random sample of the column for repeats. The sample you need grows roughly with the square root of the number of entries in the column, so for 1 million rows checking a few percent of them is enough.
